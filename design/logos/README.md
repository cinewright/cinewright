# Logos

The Cinewright logo: a film frame with sprocket perforations, beside the wordmark in Geist SemiBold (outlined, no font needed). Built on a 32-unit grid; the favicon is redrawn on a 16-unit grid so the perforations land on whole pixels.

| File | Ink | Use |
| --- | --- | --- |
| `cinewright-logo-on-dark.svg` | mark `#6D28D9` (`accent`), wordmark `#F4F0FB` (`ink-strong`, dark theme) | Full logo on dark grounds |
| `cinewright-logo-on-light.svg` | mark `#6D28D9`, wordmark `#140E22` (`ink-strong`, light theme) | Full logo on light grounds |
| `cinewright-mark.svg` | `#6D28D9` | Mark alone, 24px and up |
| `cinewright-favicon.svg` | `#6D28D9` | Favicon and anything at 16px |
| `cinewright-mark-white.svg` | `#FFFFFF` | Single colour on dark or photographic grounds |
| `cinewright-mark-black.svg` | `#000000` | Single colour on light grounds, print |

Clear space: a quarter of the mark's width on every side. Minimum size: mark 16px, full logo 96px wide. The violet mark on a dark ground sits below 3:1 contrast; use the white mark where it has to stand out on its own.
